# Hi, I'm Spencer 👋

📍 **San Jose, CA** | 🤖 **Founding Engineer @ [CoreSpeed](https://corespeed.io)** | ✍️ **[spinsirr.github.io](https://spinsirr.github.io)**

I build agent infrastructure — gateways, billing, app access and memory — and the products that run on it.

## 🛠 Now

### At CoreSpeed

- ☁️ **[CoreSpeed](https://corespeed.io)** — managed app access, built-in tools and durable memory for cloud agents. I work on the gateway, billing and public launch.
- 🕸 **Project Nebular** — multi-agent automation.

### Open source

- 🧠 **[Lore](https://github.com/corespeed-io/lore)** — memory infrastructure on Postgres + pgvector, with row-level tenant isolation and evals that separate retrieval hits from answer-bearing evidence.
- 🤖 **[Zypher Agent](https://github.com/corespeed-io/zypher-agent)** — a minimal framework for building AI agents with full control over tools, providers and execution flow.

### Side projects

- 🔧 **[Fixo](https://fixo.ink)** — AI service advisor for independent repair shops: drafts estimates and schedules work, with a human signing off. Started in 2024 as HMLS, a mobile-mechanic platform.
- 🐝 **[Hive](https://github.com/spinsirr/hive)** — a multiplayer coding-agent workspace: Claude Code or Codex runs in a cloud sandbox while teammates join the task to steer and review the changes. [Try the demo](https://hive-roan-mu.vercel.app/demo).
- 📣 **[BuildLog](https://buildlog.ink)** — turns commits, PRs and releases into draft posts for X, LinkedIn and Bluesky.
- 📦 **[OrderCue](https://github.com/spinsirr/order-wizard)** — a local-first browser extension that turns Amazon orders into a follow-up queue for reimbursements and resale.
